## RipDvD 1.3.0 — Une nouvelle interface, un vrai son d'origine

### ✨ Nouvelle interface (Linux et Windows)
- **Un écran par étape** : insérez le disque → film détecté → numérisation → terminé. Aéré, clair, thème clair et sombre.
- **Toujours un seul clic** : la langue audio et les sous-titres sont présélectionnés (français, sans sous-titres) juste au-dessus du bouton **Numériser le film**.
- **Pistes lisibles** : « Français · 5.1 » au lieu de « Piste 1 — Français (AC3) (5.1 ch) ».
- **Grand pourcentage et temps restant** pendant la numérisation.
- **Options secondaires dans le menu ☰** : analyser le disque (Ctrl+R), ouvrir le dossier des films, journal (Ctrl+L), à propos, quitter (Ctrl+Q).

### 🎯 Qualité : ce qui est annoncé est maintenant vrai
- **Résolution d'origine conservée** : les DVD européens (PAL) étaient réduits de 720×576 à 720×480. Ils gardent désormais leurs 576 lignes.
- **Son d'origine copié tel quel** : les pistes AC3 5.1 étaient réencodées en AAC. Elles sont maintenant copiées à l'identique (AC3, DTS, MP2).

### 🛠️ Corrections
- Installateur Fedora : il s'arrêtait avant d'installer quoi que ce soit.
- Installateur Windows : fonctionne quel que soit le dossier d'où il est lancé ; HandBrakeCLI (version ligne de commande) est détecté aussi dans `%LOCALAPPDATA%\HandBrake`.
- Script en ligne de commande : l'option des chapitres empêchait tout encodage.

### 📥 Installer ou mettre à jour
**Linux** (Fedora, Ubuntu, Mint, Debian, Arch) :
```bash
curl -fsSL https://raw.githubusercontent.com/asblPixels/ripdvd/main/scripts/install-linux.sh | bash
```
**Windows 10/11** : téléchargez le ZIP ci-dessous (*Source code (zip)*), puis double-cliquez sur `scripts\install-windows.bat`. Python et HandBrakeCLI sont requis : tout est expliqué dans le **manuel PDF** joint.
