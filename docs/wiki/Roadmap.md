# Roadmap

This page outlines planned features and improvements for RipDvD.

## v1.2.0 (planned)

### High priority

- [ ] **Manual title selection** — Allow the user to choose which title to rip (for TV series DVDs).
- [ ] **Multiple title queue** — Queue multiple titles for batch encoding.
- [ ] **Configuration file** — Save user preferences (`~/.config/ripdvd/config.json`).
- [ ] **Save/load presets** — Allow users to save and load custom encoding presets.

### Medium priority

- [ ] **Hardware encoding** — Intel QSV and NVIDIA NVENC support for faster encoding.
- [ ] **Audio bitrate selection** — Choose audio quality (128k, 160k, 192k, 320k).
- [ ] **Subtitle burn-in** — Option to burn subtitles into the video.
- [ ] **Output directory picker** — GUI file picker for the output directory.
- [ ] **Keyboard shortcuts** — Common shortcuts (Ctrl+R to rip, Ctrl+Q to quit, etc.).

### Low priority

- [ ] **Blu-ray support** — Support for BDMV discs.
- [ ] **DVD menu extraction** — Extract DVD menus as separate files.
- [ ] **Cover art** — Download and embed cover art in the MKV.
- [ ] **Metadata editing** — Edit title, year, genre, etc. before encoding.
- [ ] **Notifications** — Desktop notifications for encode completion.
- [ ] **Tray icon** — Minimize to system tray during encoding.

## v2.0.0 (future)

- [ ] **Plugin system** — Allow third-party plugins for custom workflows.
- [ ] **Web interface** — Optional web-based control panel.
- [ ] **Remote encoding** — Offload encoding to a remote machine.
- [ ] **Docker support** — Run RipDvD in a container.
- [ ] **macOS support** — Port to macOS.

## Community requests

These are features requested by users. Vote on [GitHub Discussions](https://github.com/asblPixels/ripdvd/discussions) to prioritize them.

- [ ] Automatic metadata fetching (TMDB/IMDb)
- [ ] Multiple audio track encoding (not just passthrough)
- [ ] Deinterlacing options in the GUI
- [ ] Crop/resize options in the GUI
- [ ] Dark mode toggle
